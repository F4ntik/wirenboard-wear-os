# Как собрать пульт и запустить его на Galaxy Watch

Здесь весь путь от исходников до первого запуска на Galaxy Watch 5 или 6. Основной пример — для Windows и PowerShell. Если нужен только готовый пульт, скачайте APK из выпуска и установите Android SDK Platform-Tools. Когда команда `adb version` заработает, переходите к разделу «Отладка на часах». Для первой проверки хватит демо. [Готовый APK](https://github.com/F4ntik/wirenboard-wear-os/releases/tag/v0.8.0) · [Скачать Platform-Tools](https://developer.android.com/tools/releases/platform-tools) · [Отладка на часах](#3-отладка-на-часах)

## 1. Подготовьте компьютер

1. Установите Android Studio с поддержкой Android Gradle Plugin 9.0.1. Пройдите мастер первого запуска. [Скачать Android Studio](https://developer.android.com/studio) · [Таблица совместимости](https://developer.android.com/studio/releases#android_gradle_plugin_and_android_studio_compatibility)
2. На стартовом экране выберите **More Actions → SDK Manager**. В открытом проекте тот же пункт доступен через **Tools → SDK Manager**. Скопируйте путь из **Android SDK Location**.
3. На вкладке **SDK Platforms** отметьте **Android 16 (API 36)**. На вкладке **SDK Tools** отметьте **Android SDK Platform-Tools**. Включите **Show Package Details** и выберите **Android SDK Build-Tools 36.0.0**. Нажмите **Apply** и примите лицензии. Platform-Tools содержит `adb` — программу, через которую компьютер устанавливает приложения на часы.
4. Для сборки из PowerShell используйте комплект Java из Android Studio или установленный JDK 17. Команды ниже настраивают **текущее окно PowerShell** для стандартных путей Windows. Если пути у вас отличаются, подставьте путь к JDK и значение **Android SDK Location** из шага 2.

```powershell
$env:JAVA_HOME = "$env:ProgramFiles\Android\Android Studio\jbr"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:Path"
java -version
adb version
```

Обе команды должны вывести версию. Для проекта подходят JDK 17 и комплект Java 21 из совместимой Android Studio. Gradle 9.1.0 загрузит скрипт из репозитория при первой сборке. [Требования Android Gradle Plugin](https://developer.android.com/build/releases/agp-9-0-0-release-notes)

## 2. Скачайте исходники и соберите APK

При установленном Git выполните команды в папке, где хотите хранить проект. Можно также открыть **Code → Download ZIP** на GitHub и распаковать архив. В обоих случаях рабочая папка — та, где лежат `settings.gradle` и `gradlew.bat`.

```powershell
git clone https://github.com/F4ntik/wirenboard-wear-os.git
cd wirenboard-wear-os
.\gradlew.bat :app:assembleDebug
```

На macOS и Linux запустите из той же папки `./gradlew :app:assembleDebug`. В конце появится **BUILD SUCCESSFUL**. Готовое приложение для установки и отладки — `app/build/outputs/apk/debug/app-debug.apk`.

Чтобы проверить свои изменения, запустите тесты и Android Lint — проверку кода и ресурсов.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
```

## 3. Отладка на часах

1. На **самих часах** откройте **Настройки → О часах → Сведения о ПО**. Быстро нажмите **Версия ПО** пять раз подряд. Дождитесь сообщения о включении режима разработчика. Названия пунктов могут немного отличаться в разных версиях One UI Watch.
2. Вернитесь в главное меню настроек. Откройте **Параметры разработчика** (или **Для разработчиков**), включите **Отладка ADB**, затем **Беспроводная отладка**. Подтвердите разрешение для своей сети, если часы его запросят.
3. Откройте **Настройки → Подключения → Wi-Fi** и проверьте, что часы подключены к той же локальной сети, что и компьютер. Для следующих шагов нужны адреса с экрана часов. Адрес Wiren Board понадобится позже, уже внутри пульта. [Инструкция Samsung с изображениями меню](https://developer.samsung.com/health/sensor/guide/connect-watch.html)

## 4. Соедините часы с компьютером

**Сначала один раз выполните сопряжение.** На часах откройте **Беспроводная отладка → Подключить новое устройство** или **Подключить с помощью кода**. Оставьте окно открытым. В PowerShell выполните следующие строки. На первый запрос введите показанный адрес целиком, включая двоеточие и порт. Когда `adb` попросит код, введите шесть цифр с того же экрана.

```powershell
$pairAddress = Read-Host "IP и порт из окна с кодом"
adb pair $pairAddress
```

**Затем подключитесь для установки.** После сообщения `Successfully paired` вернитесь на часах на один экран назад, в **Беспроводную отладку**. Возьмите адрес и порт из строки **IP-адрес и порт**. Порт подключения обычно отличается от порта сопряжения.

```powershell
$watch = Read-Host "IP и порт с основного экрана беспроводной отладки"
adb connect $watch
adb devices -l
adb -s $watch shell getprop ro.product.model
```

В списке напротив часов должен стоять статус `device`, а последняя команда покажет модель. Параметр `-s $watch` выбирает именно эти часы, даже если подключён ещё и телефон. При следующем подключении с того же компьютера обычно достаточно снова выполнить команды с `$watch`: после выключения отладки порт может измениться. На macOS и Linux используйте те же команды `adb`, подставляя адрес с портом непосредственно после `pair`, `connect` и `-s`. [Беспроводная отладка Wear OS](https://developer.android.com/training/wearables/get-started/debug-wifi)

## 5. Установите и проверьте пульт

В том же окне PowerShell, из корня проекта, установите файл, который собрали в шаге 2. Для готового APK из выпуска подставьте путь к скачанному файлу в первой команде.

```powershell
adb -s $watch install -r app/build/outputs/apk/debug/app-debug.apk
adb -s $watch shell am start -W -n com.galaxywatch.home.sample/com.galaxywatch.home.HomeActivity
```

После `Success` и `Status: ok` на часах откроется **Дом**. При первом запуске публичной сборки выберите **Посмотреть демо**, откройте **Спальню** и нажмите **Основной**. При включении появятся золотая рамка и жёлтая лампочка. В демо домашний свет не переключается.

Для своего дома установите пакет на Wiren Board, добавьте одну комнату и выберите для лампы существующий выключатель. Затем укажите в пульте локальный адрес **контроллера**. Для разработки самого шлюза отдельно описана сборка пакета Debian. [Подключение своего дома](../README.md#подключить-свой-дом) · [Сборка пакета для WB](../remote/README.md#сборка-пакета-из-исходников)

## 6. Запустите отладчик Android Studio

1. В Android Studio нажмите **Open**, выберите корневую папку проекта и дождитесь окончания **Gradle Sync**. В верхней панели выберите конфигурацию **app** и часы, модель которых вы проверили в шаге 4.
2. Для обычного запуска нажмите **Run ▶**. Чтобы увидеть выполнение кода, откройте `HomeActivity.java` и щёлкните на левом поле рядом с **первой исполняемой строкой внутри** метода `showRoom`. Красная точка — место остановки. [Исходник экрана демо](../app/src/main/java/com/galaxywatch/home/HomeActivity.java)
3. Нажмите **Debug 'app'** (значок жука). На часах в демо откройте спальню. Android Studio остановится на отмеченной строке и покажет переменные. Это позволяет убедиться, что часы исполняют код вашей сборки. Нажмите **Resume Program**, чтобы экран продолжил работу. Для настроенного дома аналогичная точка находится в `CatalogActivity.showRoom()`. [Исходник экрана настроенного дома](../app/src/main/java/com/galaxywatch/home/CatalogActivity.java)
4. Чтобы посмотреть сообщения приложения, откройте **View → Tool Windows → Logcat**, выберите часы и укажите фильтр `package:com.galaxywatch.home.sample`. После работы можно выполнить `adb disconnect $watch` и выключить беспроводную отладку на часах. Установленный пульт продолжит работать.

## Если не получилось

| Что видно | Что проверить |
| --- | --- |
| PowerShell не находит `adb`, Gradle жалуется на Java или пишет `SDK location not found` | Повторите шаг 1 в том же окне. Проверьте `adb version`, `java -version` и `.\gradlew.bat --version`. Последняя команда показывает Java, которую использует Gradle. |
| Код истёк или `adb pair` выдаёт ошибку | Заново откройте окно сопряжения на часах. Возьмите из него свежий код и порт. |
| Сопряжение прошло, но часы отсутствуют в списке или показаны как `offline` | Разбудите часы, откройте основной экран беспроводной отладки и повторите `adb connect` с текущим портом. В гостевой сети устройства могут быть изолированы друг от друга. |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | На часах уже есть приложение с тем же идентификатором, подписанное другим ключом. Чтобы сохранить его настройки, попробуйте свою сборку на эмуляторе Wear OS. Если хотите заменить установленное приложение, его удаление сотрёт настройки и привязку WB Cloud. |
