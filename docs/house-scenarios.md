# Общая кнопка и блокировка управления

Для первой установки достаточно добавить комнату и выключатель лампы. В **Интеграции → Пульт света Wear OS → Для всего дома** оба поля можно оставить пустыми. Тогда часы могут включать и выключать свет, а кнопка **Погасить весь дом** погасит светильники из всех комнат пульта после подтверждения. Правила на контроллере для этого не нужны.

## Как подключить уже готовый сценарий

| Поле в Wiren Board | Что выбрать | Что произойдёт |
| --- | --- | --- |
| **Погасить весь дом** | Кнопку вашего сценария, например «Я ухожу». Нужен доступный для записи канал типа `pushbutton`. | При подтверждении на часах пульт один раз нажмёт кнопку. За выключение отвечает ваш сценарий. Пульт дождётся, пока все лампы из его списка сообщат, что погасли. |
| **Режим «Отпуск»** | Переключатель типа `switch`, например «Блокировать управление с часов». Подойдёт и канал только для чтения, если им управляет ваша автоматика. | Пульт читает состояние. При `1` он показывает свет, но блокирует команды с часов. При `0` управление доступно. Если канал выбран, но его состояние ещё неизвестно, пульт тоже подождёт. |

Поля работают независимо. Можно подключить только кнопку «Я ухожу» и вообще не заводить «Отпуск». В каждом поле выберите канал из выпадающего списка и нажмите **Записать**. Формат адреса в редакторе — `устройство/канал`. Окончание `/on` пульт подставляет сам при отправке команды.

**Если «Я ухожу» уже работает от настенной кнопки.** Выберите виртуальную кнопку, которая запускает тот же сценарий. Если сейчас действие есть только в обработчике физического входа, вынесите выключение света в функцию и вызывайте её из обоих обработчиков. Пример виртуальной кнопки приведён ниже. Так состав светильников останется в одном месте.

**Если нужен свой режим вместо отпуска.** Например, сценарий «Уборка» может включать переключатель блокировки при старте и выключать при завершении. Если в доме уже есть подходящий переключатель, достаточно выбрать его. Блокировка распространяется только на команды пульта. Настенные выключатели и правила WB продолжают работать по своей логике. В версии 0.8.0 сообщение на часах для любой такой блокировки — «Включён режим отпуска».

**Какой сценарий подходит для общей кнопки?** Например, «Я ухожу» может дополнительно закрыть шторы, если он также гасит все лампы из пульта. Сценарий «Кино», который оставляет подсветку включённой, не подходит: пульт ждёт подтверждение выключения всех ламп. При уже погашенном свете кнопка на часах показывает **Всё выключено** и недоступна. Кнопка **Погасить здесь** в комнате действует только на её лампы и общий сценарий не вызывает.

## Пример с виртуальной лампой

Этот пример можно попробовать без подключения реле. Он создаёт на WB одно виртуальное устройство с лампой, кнопкой и переключателем блокировки.

1. В веб-интерфейсе WB откройте **Правила**, создайте новый скрипт `wear-scenes-example.js`, вставьте код ниже и сохраните. [Редактор правил Wiren Board](https://wiki.wirenboard.com/wiki/Wiren_Board_Web_Interface) · [Справочник wb-rules](https://github.com/wirenboard/wb-rules)

```js
defineVirtualDevice("wear_scenes_example", {
  title: "Пример для часов",
  cells: {
    Lamp:       { type: "switch",     value: false, title: "Пробная лампа" },
    AllOff:     { type: "pushbutton", value: false, title: "Я ухожу" },
    BlockWatch: { type: "switch",     value: false, title: "Блокировать управление с часов" }
  }
});

function turnOffExampleLights() {
  dev["wear_scenes_example/Lamp"] = false;
}

defineRule("wear_scenes_example_all_off", {
  whenChanged: "wear_scenes_example/AllOff",
  then: turnOffExampleLights
});
```

2. Откройте **Устройства → Пример для часов**. Включите **Пробная лампа** и нажмите **Я ухожу**. Виртуальная лампа должна погаснуть. Само переключение **Блокировать управление с часов** оставляет лампу в прежнем состоянии.
3. Для проверки на часах используйте тестовый пульт с одной лампой. В комнате выберите `wear_scenes_example/Lamp` как **Выключатель**. В разделе **Для всего дома** выберите `wear_scenes_example/AllOff` для **Погасить весь дом**, а `wear_scenes_example/BlockWatch` для **Режим «Отпуск»**. Нажмите **Записать**.
4. Включите пробную лампу с часов. На главном экране пульта нажмите **Погасить весь дом** и подтвердите. Затем в веб-интерфейсе WB включите блокировку — команды в пульте станут недоступны. Выключите блокировку и проверьте, что лампа снова управляется.

Чтобы применить пример у себя, замените присваивание внутри `turnOffExampleLights` вызовом вашего сценария выключения или перечислите в функции свои каналы освещения, присвоив каждому `false`. Выбирайте реальные имена каналов в разделе **Устройства**. Если нужен только переключатель блокировки, в примере достаточно оставить ячейку `BlockWatch` в `defineVirtualDevice`: функцию и обработчик общей кнопки можно убрать.

Чтобы вернуться к обычной работе, очистите соответствующее поле в **Для всего дома** и нажмите **Записать**. После очистки поля **Погасить весь дом** пульт снова выключает перечисленные лампы самостоятельно. После очистки поля **Режим «Отпуск»** пульт перестаёт ждать сигнал блокировки.
